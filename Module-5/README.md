# Module 5 – Project One

## DriverPass Business Requirements

Project One focused on analyzing the needs of the DriverPass client and documenting the business and system requirements for the proposed system.

The Business Requirements Document identifies the client's objectives, functional and nonfunctional requirements, technical requirements, security considerations, assumptions, and limitations. This project demonstrates my ability to translate information gathered from a client into organized requirements that can guide system design and development.

# Module 7 – Project Two

## DriverPass System Design

Project Two focused on transforming the DriverPass business requirements into a detailed system design. The System Design Document uses UML diagrams and technical requirements to demonstrate how the proposed system could satisfy the client's needs.

The project includes multiple UML models that represent system structure, user interactions, processes, and communication between system components. This project demonstrates the progression from requirements analysis to system design.

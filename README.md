# CS-255 System Analysis and Design

This repository contains coursework and portfolio artifacts from **CS-255: System Analysis and Design** at Southern New Hampshire University (SNHU).

## Course Overview

CS-255 focuses on the principles, methods, and techniques used to analyze business requirements and design information systems. Throughout the course, I worked with the **DriverPass** scenario to identify client needs, develop system requirements, and create system design models using Unified Modeling Language (UML).

## DriverPass Project

DriverPass is a proposed system designed to help students prepare for their driver's license exams by providing online practice tests, training resources, and the ability to schedule on-the-road driving instruction.

The project involved analyzing the client's business requirements and translating those requirements into a system design that could be understood by both technical and nontechnical stakeholders.

## Repository Contents

This repository will contain selected artifacts from the DriverPass project that demonstrate my understanding of:

* Business and system requirements
* Functional and nonfunctional requirements
* System analysis and design
* UML diagrams and process modeling
* Communicating technical system designs to different stakeholders
